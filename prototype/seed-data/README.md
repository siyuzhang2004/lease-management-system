# 统一初始化数据

本目录随仓库分发，供首次使用的浏览器初始化。当前基准整理于 2026-10-20。

- `workspace-contracts/`：深圳、耐数电子、耐数信息、日本、美国、韩国及欧洲两份合同，共八份参数。西安参数继续使用上一级的 `default-contract.json`，合计九份合同。
- `disclosures/international.json`：已提供期间的汇率与原币历史参考。不会因此接入尚未维护合同的海外公司。
- `disclosures/fixed-history.json`：欧洲旧租赁固定历史数据。
- `disclosures/opening-carry.json`：2026 年外币报表期初承接数据。
- 其余 `reference` 文件：现有单体及集团核对基准，不替代合同计算结果，不用于修改租赁负债取数。

计算表由服务根据参数重新生成，不分发缓存计算表。浏览器中的合同修改、删除记录、锁定状态和保存版本不作为共享初始化内容。

本地 `analysis/` 中的同名附注文件优先于本目录；合同按 `recordId` 合并，本地同编号合同优先。初始化不会覆盖浏览器已存在的合同，也不会恢复已删除合同。

更新统一基准时，核对源参数和附注后更新本目录并提交 Git。原始工作簿、合同原件、分析日志和浏览器存储不包含在此数据包中。
